# Experimentos históricos

Estos archivos conservan los borradores previos a la consolidación. No son
puntos de entrada soportados y pueden contener errores de API o de lógica.
Se conservan para comparar la evolución descrita en los documentos académicos.

El flujo principal está en `../workflow.py`; la web (`../app.py`), la consola
(`../cli.py`) y los nombres anteriores de los scripts llaman al mismo motor.
